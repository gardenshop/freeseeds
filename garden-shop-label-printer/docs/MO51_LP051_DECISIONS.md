## LP-051 implementation decisions

- Preserve A5-half millimetre coordinates and the 297 × 210 mm A4 sheet. Screen fit is a CSS-only scale based on the measured editor surface width; zoom never modifies layout X/Y/width/height, PDF MediaBox or printer geometry. At wide screens the scale caps at 100%; zoom may exceed fit and the canvas then scrolls.
- Keep the existing working HTML5 source-chip drag/drop. Placed fields now also move by pointer with pointer capture; the corner resize handle changes width/height. Movement uses the overlay's visible bounding rectangle to convert pointer deltas to millimetres under scaling/scroll. Placement and movement clamp to an A5 half. Clicking a source chip then clicking a face places it as a fallback. A near-identical same-source/same-position drop selects the existing field instead of creating a duplicate.
- Editor fields display the selected sample record's actual mapped value, with a short, separate binding badge. Source-field names remain in the palette/property panel. Clean preview renders the same full-sheet renderer/coordinates without editor overlays, handles, source badges or editing controls; it supports front/back, sample record and sheet navigation, PDF download/print, and selected-field font +/-/bold adjustments. Opening Preview Final MO does not call `window.print()`.
- Added a backward-compatible `bold=false` default to layout definitions; existing saved LP-048/049 layouts lacking the property load unchanged. New fields default to 10pt; font size +/- and numeric input clamp to 4–48pt. Bold and font settings persist only with source IDs/geometry; no record values are persisted.
- Added overlap detection between mapped boxes and the pinned session-only Sender CNIC. Overlap, overflow and missing sources disable mapped PDF/print until corrected. Long text remains wrapped or fails closed. The source MO artwork and label font/layout code are unchanged.
