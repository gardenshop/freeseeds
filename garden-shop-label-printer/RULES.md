## Premium Label Geometry and Data Safeguards (2026-11-08)

- Final repair geometry is A4 portrait (210 × 297 mm), with 18 labels of 65 × 44 mm. Grid x starts are 6.5, 72.5, 138.5 mm; y starts are 14, 59, 104, 149, 194, 239 mm. Horizontal and vertical gutters are exactly 1 mm.
- Outer outline is x=0.4, y=0.4, w=64.2, h=43.2 mm with 1 mm corners and 0.20 mm stroke. Source of truth is `src/layout.ts`: tracking/barcode occupy y=0.6..10.1; destination and VPL occupy the right side of that band; TO frame is (1.3,10.8,62.4,22.6); Order ID/Product share one block at y=33.7..39.0; footer starts y=39.3 mm.
- `VPL n/-` is the only printed amount style. Keep high-contrast black rules/badges and the green Garden Shop sender accent. The exact footer is `From: Garden Shop | C/o City Post Office, Sahiwal` on one row. No location pin or phone icon is printed; the landmark caption is exactly `Near by:`.
- Preview, browser print and PDF must all derive from the shared millimeter boxes and fit model. Fit each value using its active font and box; wrap address/name/product where available, reduce single-line values only to their configured minimum, and visibly flag exceptional text/barcode overflow. Never clip silently.
- Normalize mobiles to exactly 11 digits beginning `03`: preserve valid 11-digit `03...`, add `0` to a valid ten-digit `3...`, or convert valid `+92`/`92` plus ten-digit `3...` to local form. Strip standard visual separators only. Preserve invalid input for correction, flag it, render no raw invalid value, and block print/PDF until corrected. Remove only an exact phone token from displayed address text and retain the original source address.
- Code 128 uses JsBarcode's automatic Code A/B/C switching, 10X horizontal quiet zones and vector PDF bars. Canvas/PDF scale proportionally; do not pass module width below 0.19 mm. Decode against the exact tracking source and flag unscannable/too-dense values.
