# Get Free Seeds

WhatsApp-only acquisition and manual payment verification operated by Garden Shop.

The system uses Cloudflare Workers, D1, private R2, Queues, and Cloudflare Access. The production WhatsApp number is intentionally unassigned until a new number is explicitly provided by the user. Until then, all WhatsApp integration is provider-abstracted and tested with `MockWhatsAppProvider`; `MetaWhatsAppProvider` is disabled and unconfigured.

Read `rules.md` before making changes.
