# Get Free Seeds

WhatsApp-only acquisition and manual payment verification operated by Garden Shop.

The system uses Cloudflare Workers, D1, private R2, Queues, and Cloudflare Access. The authorized production WhatsApp number is `+923328883383`, but onboarding and runtime enablement remain gated on clean Meta ownership and verified credentials. Until those gates pass, all WhatsApp integration is provider-abstracted and tested with `MockWhatsAppProvider`; `MetaWhatsAppProvider` is disabled and unconfigured.

Read `rules.md` before making changes.
